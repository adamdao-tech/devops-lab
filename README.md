# DevOps Lab

Praktický trénink DevOps bez čtení článků: kvízy, psaní příkazů, hledání chyb v configu a testy na čas.
Statický web (HTML/JS), nasazení přes Cloudflare Workers (`wrangler.jsonc`, assets ve `public/`).

- `public/data/quiz.js` – otázky
- `public/data/cmds.js` – úlohy na příkazy (odpovědi jako regexy)
- `public/data/fix.js` – „najdi chybu“ scénáře

Postup se ukládá do localStorage prohlížeče (export/import v patičce).
